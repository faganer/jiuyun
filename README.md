## 客户端接入

1. 安装新版客户端。旧版本可能无法使用当前订阅，应先更新再导入。
2. 复制订阅链接导入客户端，并主动更新一次订阅。
3. 若节点仍无法使用，确认客户端中的 DNS 覆写已开启。

线路升级期间，部分节点可能出现超时，先在客户端更新订阅，再重新选择节点。
